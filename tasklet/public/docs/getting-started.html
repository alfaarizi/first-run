Getting started

This guide takes you from an empty workspace to a working task list in about two minutes.

Create your first task

Type a task name into the input at the top of the list and press Enter or click Add. The task appears at the bottom of the list immediately. Task names can be up to 200 characters.

Complete a task

Click the checkbox to the left of a task to mark it complete. Completed tasks stay visible with a strike-through until you clear them, so you can review what got done.

Clear completed tasks

Click Clear completed below the list to remove every checked task at once. Clearing is permanent: cleared tasks do not go to a trash and cannot be restored.

Keyboard shortcuts

Press Enter in the task input to add the task. Press Escape to clear the input without adding anything. There are no other shortcuts; Tasklet stays deliberately simple.

Where your tasks live

Tasks belong to a workspace. Everyone you invite to the workspace sees the same list, updated live. You can create more lists by adding projects.
