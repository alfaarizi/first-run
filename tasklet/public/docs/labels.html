Labels and filtering

Labels are colored tags you attach to tasks, and filters narrow the list to the labels you care about.

Creating a label

Open any task's menu, choose Labels, and type a new label name. Pick one of the eight colors. Labels are shared across the workspace, so the whole team uses one vocabulary.

Applying and removing labels

A task can carry up to 5 labels. Toggle a label from the task's Labels menu to apply or remove it.

Filtering by label

Click a label chip above the list to show only tasks carrying it. Click a second label to narrow further: filters combine with AND, never OR. Click the chip again to clear it.

Renaming and deleting labels

Manage labels in Settings under Labels. Renaming a label updates it on every task. Deleting a label removes it from all tasks but never deletes the tasks themselves.
