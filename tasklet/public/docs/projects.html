Projects

Projects are separate task lists inside one workspace. Use them to keep unrelated work apart, such as one project per client or per launch.

Creating a project

Open the sidebar and click New project. Give it a name up to 60 characters. The new project starts with an empty task list, and every workspace member can see it right away.

Switching between projects

Click a project's name in the sidebar to open its list. The project you viewed last loads by default the next time you open Tasklet.

Moving a task to another project

Open the task's menu and choose Move to project, then pick the destination. The task keeps its labels, due date, and assignee.

Archiving a project

Open the project's menu in the sidebar and choose Archive. Archived projects are read-only and hidden from the sidebar; restore them any time from Settings, under Archived projects. Archiving never deletes tasks.

Project limits

The Free plan includes 3 projects per workspace. The Pro plan lifts the limit to 100 projects.
