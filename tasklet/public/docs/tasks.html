Working with tasks

Tasks are the unit of work in Tasklet. Each task has a name, an optional due date, optional labels, and an optional assignee.

Editing a task

Double-click a task's name to edit it in place. Press Enter to save or Escape to discard the edit. Edits sync to every workspace member within a few seconds.

Reordering tasks

Drag a task by its handle to reorder it within the list. New tasks always start at the bottom. Order is shared: dragging a task moves it for everyone in the workspace.

Deleting a single task

Hover over a task and click the trash icon on the right to delete it. Deleting is permanent. To remove many finished tasks at once, use Clear completed instead.

Task limits

A list holds up to 500 open tasks on the Free plan and 5,000 on the Pro plan. Completed tasks do not count against the limit once cleared.

Recovering mistakes

There is no undo for deleting or clearing tasks. If you cleared something you still need, re-create it; task history is not kept on the Free plan.
